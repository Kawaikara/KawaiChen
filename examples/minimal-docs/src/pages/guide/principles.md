# Design principles

## Astro stays visible

KawaiChen does not trap content inside a proprietary file structure. Anything Astro understands should remain available to a KawaiChen project.

## Adopt only what you need

Documentation layouts, headers, and design tokens can be adopted independently. None of them are forced onto free-form pages.

## Pages outlive features

Documents and links should remain available when optional features are disabled or JavaScript fails.
