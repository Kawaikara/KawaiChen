# A small, adaptable documentation foundation

This example uses the default KawaiChen documentation layout. Its content is ordinary Markdown, while the project retains ownership of its identity and navigation structure.

## Installation

```sh
npm install kawaichen astro
```

## An important boundary

KawaiChen provides a readable default shell without taking ownership of your routes or content. Astro pages, Markdown, and MDX can be combined as the project requires.
